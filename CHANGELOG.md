# Release notes

## 0.8.0 — 2026-11-11

Aegis Linux Hardener provides a unified terminal environment for Debian-based system administration.

- Live dashboard, process monitoring and categorized application catalog with live search.
- Reviewed security controls, SSH, Fail2Ban, UFW, AppArmor and selected Lynis recommendations.
- Network, DNS, hosts and hostname configuration with protected activation and recovery.
- Local users, groups, SSH public keys, permissions and POSIX ACL management.
- Standalone Samba shares, credentials, client inspection and service controls.
- Categorized logs, exports and Telegram notifications.
- Custom APT catalog entries, installed status, supported launchers and guarded removal.
- English/Greek interface, theme-aware dialogs and ten themes.
- Portable/installed operation, explicit online updates, action history, backups and scoped Undo.

See [README.md](README.md) or [README.el.md](README.el.md) for requirements, operating procedures and recovery limits.
